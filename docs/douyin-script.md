## 口播正文

投了200份简历，只收到3个回复。直到我发现——问题不在我的能力，在我给HR发的第一句话。

"您好，对贵公司岗位很感兴趣"、"希望能进一步了解"——HR一天收几百条这个，轮得到你吗？

所以我写了个插件，叫 JobMate。

打开 Boss 直聘的职位页面，右上角自动弹出一个面板。点一下，AI 同时做三件事：读 JD、对照你的简历、生成一条针对这个职位的招呼语。不是模板，是真正匹配你经历的话。

更狠的是它会给你打一个匹配度分数。

你看——这个大厂前端岗，85分，核心技能全中，建议投。再看这个车企工程师，12分，跨行业了，它直接告诉我不值得浪费时间。

投之前看一眼分数，省掉多少无效投递。

插件叫 JobMate，Chrome 浏览器扩展，完全免费，只需要你自己的 DeepSeek API Key。链接在评论区。
