# JobMate 抖音口播脚本

## 口播正文

Boss直聘上90%的人打招呼都在写废话，HR根本不会点开。

投了几百份简历，回复寥寥无几。后来我发现——问题不在能力，在第一句话。

"您好，对贵公司岗位很感兴趣"——HR一天收几百条一模一样的，你觉得她会回吗？

所以我开始把JD和简历一起丢给DeepSeek，让它给我打分。超过80分就生成一条针对性的招呼语，我再发给HR。就这一个动作，回复率至少翻了一倍。

但每次都复制粘贴JD太烦了，我干脆写了个浏览器扩展，叫 JobMate。

打开Boss直聘刷职位的时候，右上角自动弹出一个面板。点一下，AI同时做三件事：读JD、对照你的简历、生成招呼语。还会给你一个匹配度分——这个岗位值不值得投，一眼就知道。

80分以上，投。60分以下，跳过，不浪费时间。

只要你在Boss直聘找工作就都能用。完全免费，只需要你自己的DeepSeek API Key。

使用文档放评论区了，觉得有用就去试试。
