# JobMate — AI 求职助手使用指南

## 这是什么？

JobMate 是一个 Chrome 浏览器扩展，帮你在 Boss 直聘上自动分析职位匹配度并一键生成个性化招呼语。

简单说：不用再手写"您好想了解一下"，AI 帮你判断这个职位值不值得投，还帮你写好第一句话。

---

## 怎么装？

1. 下载 `jobmate-0.1.0-chrome.zip`，解压到任意文件夹
2. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/`
3. 打开右上角「开发者模式」开关
4. 点击「加载已解压的扩展程序」→ 选择刚才解压的文件夹
5. 搞定

---

## 怎么配置？

装好之后，点浏览器右上角的 JobMate 图标（绿色公文包），弹出设置面板：

**必须配置：**

- **DeepSeek API Key**：AI 的钥匙。去 DeepSeek 官网注册，充 10 块钱够用一个月。
- **上传简历**：支持 PDF 或 Word 格式。可以传多份，点击切换。

---

## 怎么用？

### 第一步：打开职位

在 Boss 直聘上正常浏览，打开任意一个职位详情页。

### 第二步：生成招呼语

页面右上角出现 JobMate 浮动面板，选择侧重点：

| 按钮 | 什么时候用 |
|------|-----------|
| **通用** | 均衡匹配 |
| **技能** | 强调技术栈匹配 |
| **经验匹配** | 强调行业背景和年限 |
| **项目经历** | 强调做过的项目 |

AI 返回：匹配度分数、招呼语（自动复制）、评分理由。

### 第三步：发送

点「立即沟通」→ 聊天框 Ctrl+V 粘贴 → 发送。

---

## 匹配度怎么看？

| 分数 | 建议 |
|------|------|
| 80-100 | 核心能力高度匹配，建议投 |
| 60-80 | 部分匹配，可以投 |
| <60 | 不匹配或跨行业，不建议 |

技术岗匹配严格（前端投后端→0分），通用岗相对宽松。

---

## 历史缓存

生成的招呼语自动保存。点「查历史招呼语 →」直接取出。

---

## 隐私安全

- 简历仅在你电脑上解析，不经过任何服务器
- API Key 你自己申请，存在本地
- 使用统计仅记录生成次数，不含简历和JD内容

---

## 常见问题

**Q：为什么要自己提供 API Key？**

A：数据只走你自己的 DeepSeek 账号，我们看不到。

**Q：能用在 51job 或智联吗？**

A：不能，它们需要手机 App 投递。

**Q：提示"Extension context invalidated"？**

A：关闭 Boss 直聘页面重新打开即可。
